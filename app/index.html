ID トークンについて（初めての方へ）

ID トークンは「Google でログインした」ことを示す証明書です。ブラウザではなく、リバースプロキシ（oauth2-proxy など）が Google から受け取ります。

このデモは「アプリが自分で ID トークンを検証する」流れを学ぶためのものです。そのため、プロキシがログイン後のリクエストに ID トークンを付けてアプリへ渡す設定が必要です。ここに「SSO ログインが必要です」と出る場合は、ログイン済みでも ID トークンがアプリに届いていません。

通常の本番では、ログイン確認はプロキシが済ませるので、ID トークンはアプリへ渡さないのが基本です（メールアドレスなど結果だけを渡します）。トークンは漏れると悪用できる秘密情報なので、自分で検証が必要なアプリにだけ渡してください。このデモは学習用に渡し、画面にも表示しています。

渡し方の概要は README の「ID トークンをアプリに渡す設定」を参照してください。
