ID トークンについて（初めての方へ）

ID トークンは「Google でログインした」ことを示す証明書です。ブラウザではなく、リバースプロキシ（oauth2-proxy など）が Google から受け取ります。

このアプリは ID トークンを、標準ではない独自ヘッダー（既定は X-Forwarded-Id-Token。環境変数 SSO_ID_TOKEN_HEADER で変更可）で受け取ります。標準とは、認証情報を運ぶために HTTP で決められた Authorization ヘッダー（例：Authorization: Bearer ...）のことです。このアプリは Authorization を API のアクセストークン用に使うため、ID トークンは別の独自ヘッダーで受け取ります。

届いていれば、このページに「SSO ログイン済み」と ID トークンが表示されます。

通常の本番では、ログイン確認はプロキシが済ませるので、ID トークンはアプリへ渡さないのが基本です（メールアドレスなど結果だけを渡します）。トークンは漏れると悪用できる秘密情報なので、自分で検証が必要なアプリにだけ渡してください。このデモは学習用に渡し、画面にも表示しています。

渡し方の概要は README の「ID トークンをアプリに渡す設定」を参照してください。
